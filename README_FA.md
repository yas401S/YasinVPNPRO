# Yasin VPN PRO — اندروید

پروژه اندرویدی Kotlin و Jetpack Compose با موتور WireGuard.

## قابلیت‌های پیاده‌سازی‌شده
- رابط کاربری فارسی و راست‌چین
- وارد کردن فایل کانفیگ WireGuard از حافظه با انتخاب‌گر رسمی اندروید
- نگهداری مجوز خواندن فایل انتخاب‌شده و بازیابی کانفیگ پس از بازشدن دوباره برنامه (در صورت پشتیبانی ارائه‌دهنده فایل)
- اتصال و قطع تونل با اجرای عملیات در صف کاری تک‌نخی
- نمایش وضعیت تونل از رویدادهای موتور WireGuard
- غیرفعال‌کردن کنترل‌ها هنگام عملیات اتصال/قطع برای جلوگیری از درخواست‌های هم‌زمان
- عدم درخواست مجوز مخاطبین، پیامک، عکس‌ها، فایل‌های عمومی، دوربین، میکروفون یا موقعیت مکانی
- غیرفعال بودن پشتیبان‌گیری اندروید و ارتباطات متنی ناامن (cleartext)

## نکته مهم درباره حریم خصوصی
برنامه برای کارکرد VPN به مجوز سیستمی VPN و اینترنت نیاز دارد. این مجوز به معنی دسترسی به مخاطبین یا گالری نیست. با این حال، سرور VPN می‌تواند IP مقصد، زمان و حجم ارتباط را مشاهده کند و ممکن است محتوای فاقد رمزنگاری سرتاسری را بخواند. HTTPS همچنان باید فعال باشد. از کانفیگ‌های ناشناس برای حساب‌ها و اطلاعات حساس استفاده نکنید.

## مواردی که هنوز پیاده‌سازی یا راستی‌آزمایی نشده‌اند
- فهرست سرور رایگانِ معتبر و بررسی‌شده؛ این پروژه فعلاً کانفیگ واردشده توسط کاربر را استفاده می‌کند.
- موتور OpenVPN
- انتخاب خودکار سرور بر اساس پینگ، سرعت و پایداری
- Kill Switch قابل اتکا، محافظت تکمیلی DNS و آزمون نشت IP/DNS
- آمار دقیق مصرف و اتصال مجدد خودکار
- آزمون عملی اتصال روی دستگاه‌های واقعی و ممیزی امنیتی مستقل
