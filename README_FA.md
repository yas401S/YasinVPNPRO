# Yasin VPN PRO — اندروید

نسخه اولیه پروژه Kotlin و Jetpack Compose با موتور WireGuard.

- رابط کاربری فارسی
- وارد کردن فایل کانفیگ WireGuard
- اتصال و قطع تونل
- عدم درخواست مجوز مخاطبین، پیامک، گالری، دوربین، میکروفون و موقعیت مکانی

## نکته امنیتی
سرور VPN می‌تواند IP مقصد، زمان و حجم ارتباط را ببیند و محتوای فاقد رمزنگاری سرتاسری را بخواند. از کانفیگ‌های ناشناس برای اطلاعات حساس استفاده نکنید.

## محدودیت‌ها
این نسخه هنوز فهرست سرور رایگان تأییدشده، OpenVPN، سنجش پینگ و سرعت، Kill Switch و تست نشت را ندارد. تا وقتی سرور معتبر در اختیار نباشد اتصال انجام نمی‌شود. ساخت موفق APK نیز باید در GitHub Actions تأیید شود.
